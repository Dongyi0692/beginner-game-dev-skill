# 小白也能直接上手的游戏开发 Skill

帮助初学者和个人开发者从游戏想法出发，整理需求、规划原型、制作资源、设计玩法系统并交付可运行版本。支持 Unity、团结引擎和其他引擎；根据项目实际需要选用内容。

## 安装

将本仓库的 `game-dev-guide` 文件夹复制到 Codex 的技能目录（通常是 `~/.codex/skills/`），重新加载技能或重启客户端。具体路径以你的 Codex 环境为准。不要把整个仓库嵌套成额外一级技能目录。

## 使用

在 Codex 对话中输入：`$game-dev-guide 我想做一款……`，并说明想先讨论、做需求问答、写策划，还是实施已确定的功能。你可以用口语描述需求，分批回答问题。

涉及项目搭建、资源导入、批量修改或构建的操作脚本时，Skill 会在生成前询问本次是否需要运行验证。具体用户授权和项目现有规则优先。

## 内容与边界

包括规划问答、制作流程、资源生产及战斗与数值等系统的条件性指导。它提供问题和决策方法，不保证商业成功、自动生成完整游戏或代替实际测试与玩家验收。根据项目需要调查引擎、平台、素材授权和发布要求。

本项目以既有《游戏开发全流程通用规范》v1.2 为基础整理；面向公开使用时，个人电脑路径和个人项目约定改为可配置。欢迎基于实际使用反馈提出建议。
