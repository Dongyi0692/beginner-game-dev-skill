# Planning

Start by identifying the player's intended experience, audience, platform, controls, team, constraints and what the current stage must deliver. Use the questionnaire as a pool for a project-specific complete questionnaire; preserve answers already supplied and indicate their sources. Its 18 dimensions and 108 questions are a baseline, not 108 immediate questions to ask in chat. Mark inapplicable items with a reason. Do not infer consent from silence.

Turn answers into confirmed goals, playable loop, scope (must/optional/deferred), assumptions, dependencies, milestones and practical acceptance conditions. Align time, budget, tools and risk with the project. Do not automatically add combat, a particular platform or a fixed deadline.

For implementation, prioritize a small playable loop, then a representative end-to-end slice, before multiplying content. Revise scope with the user when evidence changes expected costs or experience.
