# Asset production and integration

Start from the game's confirmed visual and audio direction, player needs and target platform. Inventory the assets needed for a playable slice and identify dependencies before bulk production. For each asset family agree, as applicable, on style references, dimensions, format, perspective, pivot, animation states, naming, import settings and in-game size. Treat these as project-specific decisions.

Produce a representative character, scene, UI page or sound first; check the result in the target context and obtain aesthetic approval before multiplying it. Distinguish generated originals from edited import-ready versions and actual integrated resources. Keep source, creator/tool, prompt where relevant, license, permitted uses and attribution; do not assume AI generation implies ownership or commercial rights.

Integrate incrementally: check engine import and references, hierarchy and layering, animation alignment, text readability, audio loudness and transitions as applicable. Automated or editor checks support but do not replace a user's visual or listening acceptance. Avoid generating unused assets unless they serve an agreed exploration goal.
